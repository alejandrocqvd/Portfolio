# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal portfolio site (deployed at https://acardona.ca) built with Next.js 15 App Router, React 18, Tailwind CSS 3, plain JavaScript (`.jsx`, no TypeScript). Requires Node 24.x (`engines` in `package.json`).

## Commands

```bash
npm run dev     # dev server at http://localhost:3000
npm run build   # production build
npm run start   # serve the production build
npm run lint    # next lint (extends next/core-web-vitals)
```

There is no test suite. `next-sitemap.config.js` exists, but no `postbuild` script runs `next-sitemap`, so the sitemap/robots.txt are not generated by `npm run build`.

## Architecture

- **Routes** live in `src/app/`: `/` (`page.jsx`), `/about`, `/projects`, `/contact`. Components used by only one route sit next to that route's `page.jsx` (e.g. `projects/ProjectPopup.jsx`, `about/Timeline.jsx`); shared components (`Navbar`, `Footer`, `PhotoRow`) are in `src/components/`.
- **Layout**: `src/app/layout.jsx` wraps everything in `ViewTransitions` from `next-view-transitions` and mounts `Background`, `Navbar` (fixed to the top; it gains a translucent blurred backing once the page scrolls), `<main>` and `Footer` (pages do not render their own footer). Internal navigation should use `Link` from `next-view-transitions`, not `next/link`, to keep page transitions working. Only the `.page-vt` wrapper (main + footer) animates between routes.
- **Theme**: an inline script in `layout.jsx` sets `data-theme` (`light`/`dark`) and `data-os` on `<html>` before paint. Change the theme only through `toggleTheme` in `src/lib/display.js` (view-transition reveal: a feathered circle from the toggle); read it with `useTheme()`.
- **Shared data**: `src/lib/site.js` (routes, email, external links) feeds the navbar, command menu (⌘K / Ctrl+K, `src/components/CommandMenu.jsx`) and footer. `src/lib/now.js` holds the footer's "now" getters (location, weather, recent game/song), currently stubs, server-side so API keys stay private.
- **Path aliases** (`jsconfig.json`): `@/*` → `src/*`, `@public/*` → `public/*`. Images under `public/` are often statically imported via `@public/...` (giving Next `Image` width/height/blur), while project media are referenced as URL strings (`/work/...`).
- **Content is hardcoded data in components**, not in a CMS or JSON files:
  - Projects: `src/app/projects/catalogue.js` defines `featuredProject` (adds a `blurb`), a `projects` map, and `projectCards` (bento-grid layout only: `{ id, side }`, text and image come from `projects[id]`). Each project has `title`, `subtitle`, `thumbnail` (card image), `links`, `images` (`.mp4`/`.webm`/`.ogg` entries render as video), `header`, `description`, and `techStack: stack("React", ...)`. Skill logos live in the catalogue's `skills` table; `stack()` throws on unknown names. `SkillBox` derives shade and rounding from position. Terms are in `GLOSSARY.md`. Clicking a card opens `ProjectDialog` (`ProjectPopup.jsx`, one responsive native `<dialog>`). `/projects?p=<id>` opens a project directly (`featured` for the featured one).
  - Experience/education: `timelineItems` in `src/app/about/Timeline.jsx`. A period containing "Now" marks the role as current (accent node).
  - Contact: the direct links as a row of cards, then `src/app/contact/CatRun.jsx`, a pixel-art canvas endless runner with classic offline-runner rules (speed climbs to a cap, score blinks every 100, cucumber groups, a roomba after 100, butterflies at speed). Space/↑/tap jumps, ↓ ducks and fast-falls; touch devices never get the duck-only butterfly height. Tuning is the `RULES` block at the top; best score in `localStorage`.
  - Resume: `public/misc/Alejandro-Cardona-Resume.pdf` (replaced directly when updated).
- **Intro**: `src/components/Loader.jsx` (server, CSS-only) plays once per session (`data-intro="skip"` set by the head script afterwards): logo, then the signature written by hand-traced mask strokes, then the logo glides into the navbar (`.intro-track` mirrors the navbar's width and padding, so keep them in sync). Its length is `--intro` in `globals.css`; anything that should wait for it (hero rule, `Greeting`) reads that variable.
- **Home**: `src/app/Greeting.jsx` cycles "Hello, I’m" in 14 languages continuously (English first, rest shuffled, same order repeats; pauses on hover and in background tabs, static under reduced motion). Non-Latin glyphs come from small (2–14 KB) subsets in `public/fonts/hello/` via the `Hello Script` font-face (in the body font stack). Left of the bio, `src/app/PhotoCards.jsx` fans three photos (data with alt text in `page.jsx`): middle straight and on top, sides tilted behind; hovering a card lifts it and fades a copy of it in above the pile, so it rises through the cards in front of it instead of clipping over them. `PhotoRow` is now used only on About.
- **Background** is a raw WebGL2 point lattice rendered in a Web Worker on an OffscreenCanvas (`src/components/lattice.worker.js`, driven by `Background.jsx`; no three.js), so it never blocks the main thread. Started on idle, paused off-screen, still under reduced motion, rippled by clicks and nudged away from the mouse (`{ ripple }` / `{ cursor }` messages; tuning constants `RIPPLE`, `CURSOR`, `LIGHT_DOT_SCALE` at the top of the worker), inverted by CSS in light mode. Without OffscreenCanvas or a GPU (`failIfMajorPerformanceCaveat`) it falls back to CSS dots.
- **Styling**: Tailwind utilities mapped to theme tokens (`paper`, `surface`, `ink`, `muted`, `accent` as RGB channels in `src/globals.css`, so `bg-ink/10` works), radii `rounded-control` (8) / `rounded-media` (10) / `rounded-overlay` (16), easing `ease-out` = `cubic-bezier(0.23,1,0.32,1)`. Font is Spline Sans via `next/font`. `globals.css` also holds the intro, greeting roll, timeline spine, dialog and view-transition styles, and the skill-box hover styles. Motion rules: one easing (`--ease`), 150/250/400 ms durations, one orchestrated moment per page, everything else answers a user action; every animation has a `prefers-reduced-motion` fallback in the block at the end of the motion section. Custom breakpoints `3xl` (1800px) and `4xl` (3000px) are in `tailwind.config.js`.
- Most components are client components (`"use client"`).

## Conventions

- Commit messages are prefixed `MAJOR:`, `MINOR:`, or `PATCH:`, and the `version` in `package.json` (and `package-lock.json`) is bumped to match in the same commit.
- Code files separate top-level components with a `// ====...` divider comment line.
