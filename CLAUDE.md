# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal portfolio site (deployed at https://acardona.ca) built with Next.js 15 App Router, React 18, Tailwind CSS 3, plain JavaScript (`.jsx`, no TypeScript). Requires Node 24.x (`engines` in `package.json`).

## Commands

```bash
npm run dev     # dev server at http://localhost:3000
npm run build   # production build; postbuild runs next-sitemap (sitemap.xml + robots.txt into public/, gitignored)
npm run start   # serve the production build
npm run lint    # next lint (extends next/core-web-vitals)
```

There is no test suite.

Each section folder (`src/app`, `src/app/about`, `src/app/contact`, `src/app/projects`, `src/components`, `src/lib`) has a human-oriented `README.md` explaining its architecture; keep it in sync when a section's design changes.

## Architecture

- **Routes** live in `src/app/`: `/` (`page.jsx`), `/about`, `/projects`, `/contact`. Components used by only one route sit next to that route's `page.jsx` (e.g. `projects/ProjectPopup.jsx`, `about/Timeline.jsx`); shared components (`Navbar`, `Footer`) are in `src/components/`.
- **Layout**: `src/app/layout.jsx` wraps everything in `ViewTransitions` from `next-view-transitions` and mounts `Background`, `Navbar`, `<main>` and `Footer` (pages do not render their own footer). Internal navigation should use `Link` from `next-view-transitions`, not `next/link`, to keep page transitions working. Only the `.page-vt` wrapper (main + footer) animates between routes. A click that lands on a running transition's snapshot skips it and clicks the link underneath (`src/components/TransitionClicks.jsx`), so links never wait out an animation.
- **Theme**: an inline script in `layout.jsx` sets `data-theme` (`light`/`dark`) and `data-os` on `<html>` before paint. Change the theme only through `toggleTheme` in `src/lib/display.js` (view-transition reveal: a feathered circle from the toggle); read it with `useTheme()`.
- **Shared data**: `src/lib/site.js` (routes, email, external links) feeds the navbar, command menu (⌘K / Ctrl+K, `src/components/CommandMenu.jsx`) and footer. `src/lib/now.js` holds the footer's "now" getters, server-side so keys stay private: Calgary weather from Open-Meteo (no key), recent game from the Steam Web API (`STEAM_API_KEY`, `STEAM_ID`), recent song from Spotify (`SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REFRESH_TOKEN`, obtained once with `scripts/spotify-token.mjs`). Each returns null on failure or a missing key; `.env.example` lists the variables; `export const revalidate = 300` in `layout.jsx` refreshes pages (and this data) every 5 minutes.
- **Path aliases** (`jsconfig.json`): `@/*` → `src/*`, `@public/*` → `public/*`. Images under `public/` are often statically imported via `@public/...` (giving Next `Image` width/height/blur), while project media are referenced as URL strings (`/work/...`).
- **Content is hardcoded data in components**, not in a CMS or JSON files:
  - Projects: `src/app/projects/catalogue.js` defines `featuredProject` (adds a `blurb`), a `projects` map, and `projectCards` (bento-grid layout only: `{ id, side }`, text and image come from `projects[id]`). Each project has `title`, `subtitle`, `thumbnail` (card image), `links`, `images` (`.mp4`/`.webm`/`.ogg` entries render as video), `header`, `description`, and `techStack: stack("React", ...)`. Skill logos live in the catalogue's `skills` table; `stack()` throws on unknown names. `SkillBox` derives shade and rounding from position. Terms are in `GLOSSARY.md`. Clicking a card opens `ProjectDialog` (`ProjectPopup.jsx`, one responsive native `<dialog>`). `/projects?p=<id>` opens a project directly (`featured` for the featured one).
  - Experience/education: `timelineItems` in `src/app/about/Timeline.jsx` (each with a `short` lane label), drawn as a year track: one lane per role on a shared axis (January of the first year to January after this one), oldest first, with year lines and an accent "Now" line. Lanes are ARIA tabs (whole row is the target, selects on press, arrow keys/Home/End) for the details panel below (role, period, duration, bullets). A period containing "Now" marks the role as current (accent bar, runs to the end of this month). Bars are `rounded-full`, except the right end of a bar that reaches "Now" (`rounded-r-none`); the selected lane gets a blinking ▶ (`.lane-marker`). Bars grow in after `--intro` (`.year-bar`). Between the intro blurb and the chart, `PhotoStrip` shows the 4 `photos` as an accordion (featured photo `flex-grow` 6, the rest 1; mouse hover or tap features one). The resume line follows the panel.
  - Contact: a split hero in the Projects hero's frame: heading, blurb and "Email me" + "Copy email" buttons (`CopyButton.jsx`, icon-only unless given `className`/`children`) on the left, `elsewhere` as hairline rows on the right (label, value underlined on hover, profiles show the handle). Below a hairline, full width, `src/app/contact/CatRun.jsx`, a pixel-art canvas endless runner with classic offline-runner rules (speed climbs to a cap, score blinks every 100, cucumber groups, a roomba after 100, butterflies at speed). Space/↑/tap jumps, ↓ ducks and fast-falls; touch devices never get the duck-only butterfly height. Tuning is the `RULES` block at the top; best score in `localStorage`. Sprites are character-grid strings mapped through palettes; Jiji's fur (`FUR`), eyes (`EYES`) and the cucumbers (`CUCUMBER_COLORS`, drawn procedurally by `drawCucumber`) use fixed colours, everything else follows theme tokens. "Jiji" in the heading is `JijiName`: bold, underlined, with a CSS-only hover/focus card showing `public/about/jiji.png`.
  - Resume: `public/misc/Alejandro-Cardona-Resume.pdf` (replaced directly when updated).
- **Intro**: `src/components/Loader.jsx` (server, CSS-only) plays on every full page load, refreshes included (client-side navigation keeps the layout, so it doesn't replay; the home hero rule sets `data-intro="skip"` when it finishes, and `Navbar` sets it on the first client-side navigation): the logo's 8 blades spin as a loading ring (one lit blade with a fading tail, stepping clockwise), the A fades in while it spins, the spin stops once the A is fully in, the blades after the lit one fill to full one per step (clockwise, so the tail catches up last), then the logo glows as the last blade lands, holds, and glides into the navbar as the page fades in (`.intro-logo`'s `--slot` mirrors the navbar's width and padding, so keep them in sync). The A and blades are read from `public/misc/logo_white.svg` by path index. Its length is `--intro` in `globals.css`, derived from the values to tune: `--intro-step` (seconds per blade), `--intro-spin` (seconds before the A), `--intro-a` (A fade-in), `--intro-glow` (glow bloom), `--intro-hold` (lit, glowing hold) and `--intro-fade` (glide and dissolve into the page), written as plain numbers like `0.5` (registered as `<number>`, so invalid values fall back to the defaults); anything that should wait for it (hero rule, `Greeting`) reads `--intro`.
- **Home**: `src/app/Greeting.jsx` cycles "Hello, I’m" in 14 languages continuously (English first, rest shuffled, same order repeats; pauses on hover and in background tabs, static under reduced motion). Non-Latin glyphs come from small (2–14 KB) subsets in `public/fonts/hello/` via the `Hello Script` font-face (in the body font stack). Left of the bio, `src/app/PhotoCards.jsx` stacks three photos (data with alt text in `page.jsx`): square, untilted, as tall as the bio (the pile stretches to the grid row on lg, 8:5 when stacked), sides flush with the column edges and the middle centred on top; hovering a card fades in and grows a copy of it above the pile, so it rises through the cards in front of it instead of clipping over them; the middle card's raised resting look is its copy too. The pile cards themselves never move: a visible card whose scale transition settles pops on its last frame (resampled while scaled, redrawn crisp and pixel-snapped after), so only copies animate, ending fully shown at the lifted pose or fully faded.
- **Background** is a raw WebGL2 point lattice rendered in a Web Worker on an OffscreenCanvas (`src/components/lattice.worker.js`, driven by `Background.jsx`; no three.js), so it never blocks the main thread. Started on idle, paused off-screen, still under reduced motion, rippled by clicks and nudged away from the mouse (`{ ripple }` / `{ cursor }` messages; tuning constants `RIPPLE`, `CURSOR`, `LIGHT_DOT_SCALE` at the top of the worker), inverted by CSS in light mode. Ripples only fire on bare background: `onContent` in `Background.jsx` skips clicks on controls/media, on any element (or ancestor) with a background or border, and on text line boxes. Without OffscreenCanvas or a GPU (`failIfMajorPerformanceCaveat`) it falls back to CSS dots.
- **Styling**: Tailwind utilities mapped to theme tokens (`paper`, `surface`, `ink`, `muted`, `accent` as RGB channels in `src/globals.css`, so `bg-ink/10` works), radii `rounded-control` (8) / `rounded-media` (10) / `rounded-overlay` (16), easing `ease-out` = `cubic-bezier(0.23,1,0.32,1)`. Font is JetBrains Mono (variable, upright + italic) self-hosted from `public/fonts/hello` via `next/font/local` in `layout.jsx`, exposed as `--font-sans`. `globals.css` also holds the intro, greeting roll, timeline year-bar/lane-marker, dialog and view-transition styles, and the skill-box hover styles. Motion rules: one easing (`--ease`), 150/250/400 ms durations, one orchestrated moment per page, everything else answers a user action; every animation has a `prefers-reduced-motion` fallback in the block at the end of the motion section.
- **SEO**: `src/lib/seo.js` holds `pageMetadata({ path, title, description })` (title, description, canonical, Open Graph and Twitter tags incl. the share image) and `personJsonLd` (schema.org Person, rendered in the root layout's `<head>`). The root layout sets `metadataBase` and the `Alejandro Cardona | %s` title template; `/about` and `/contact` export `metadata` from their pages, `/projects` from a pass-through `projects/layout.jsx` (its page is a client component). Canonicals drop query strings, so `/projects?p=<id>` points at `/projects`. `src/app/opengraph-image.jsx` renders the 1200×630 share card (`next/og`); `next-sitemap.config.js` excludes it from the sitemap.
- Most components are client components (`"use client"`).
