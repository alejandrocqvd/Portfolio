# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Personal portfolio site (deployed at https://acardona.ca) built with Next.js 15 App Router, React 18, Tailwind CSS 3, plain JavaScript (`.jsx`, no TypeScript). Requires Node 24.x (`engines` in `package.json`).

## Commands

```bash
npm run dev     # dev server at http://localhost:3000
npm run build   # production build
npm run start   # serve the production build
npm run lint    # next lint (extends next/core-web-vitals)
```

There is no test suite. `next-sitemap.config.js` exists, but no `postbuild` script runs `next-sitemap`, so the sitemap/robots.txt are not generated by `npm run build`.

## Architecture

- **Routes** live in `src/app/`: `/` (`page.jsx`), `/about`, `/projects`, `/contact`. Components used by only one route sit next to that route's `page.jsx` (e.g. `projects/ProjectPopup.jsx`, `about/Timeline.jsx`); shared components (`Navbar`, `Footer`, `PhotoRow`) are in `src/components/`.
- **Layout**: `src/app/layout.jsx` wraps everything in `ViewTransitions` from `next-view-transitions`. Internal navigation should use `Link` from `next-view-transitions`, not `next/link`, to keep page transitions working. Each page renders its own `<Footer />`; the navbar is in the layout.
- **Path aliases** (`jsconfig.json`): `@/*` → `src/*`, `@public/*` → `public/*`. Images under `public/` are often statically imported via `@public/...` (giving Next `Image` width/height/blur), while project media are referenced as URL strings (`/work/...`).
- **Content is hardcoded data in components**, not in a CMS or JSON files:
  - Projects: `src/app/projects/catalogue.js` defines `featuredProject` (adds a `blurb`), a `projects` map, and `projectCards` (bento-grid layout only: `{ id, side, fade }`, text and image come from `projects[id]`). Each project has `title`, `subtitle`, `thumbnail` (card image), `links`, `images` (`.mp4`/`.webm`/`.ogg` entries render as video), `header`, `description`, and `techStack: stack("React", ...)`. Skill logos live in the catalogue's `skills` table; `stack()` throws on unknown names. `SkillBox` derives shade and rounding from position. Terms are in `GLOSSARY.md`. Clicking a card sets `activeProject` and opens `ProjectPopUpContainer`, which renders separate desktop/mobile popups split at the `md` breakpoint.
  - Experience/education: `timelineItems` in `src/app/about/Timeline.jsx`.
  - Resume: `public/misc/Alejandro-Cardona-Resume.pdf` (replaced directly when updated).
- **Home hero background** is a Three.js GLSL shader (`src/app/GSLHills.jsx`) rendered in a client component.
- **Styling**: Tailwind utilities plus custom classes in `src/globals.css` — theme CSS variables, the self-hosted Roboto variable font, skill-box hover styles, and staggered entrance animations (`fade-up-*`, `fade-in-*` classes driven by `--fade-delay`/`--fade-distance`/`--fade-duration`). Reuse these classes for entrance animations rather than adding new keyframes. Custom breakpoints `3xl` (1800px) and `4xl` (3000px) are in `tailwind.config.js`.
- Most components are client components (`"use client"`).

## Conventions

- Commit messages are prefixed `MAJOR:`, `MINOR:`, or `PATCH:`, and the `version` in `package.json` (and `package-lock.json`) is bumped to match in the same commit.
- Code files separate top-level components with a `// ====...` divider comment line.
